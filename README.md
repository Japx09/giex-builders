## 🌟 Overview

A modern, high-performance web experience built for **Giex Builders**. Designed around **client trust, radical transparency, and human engineer stewardship**, moving away from generic construction templates.

### ✨ Key Features

- **Pill Navigation & Kinetic Hairline Tracker**: Fixed pill navigation with backdrop blur and spring-physics reading progress.
- **Client-Centric Hero Arc**: Visual cards featuring genuine client interactions, consultations, and happy homeowners.
- **Interactive Budget & Pag-IBIG Estimator**: Live Philippine Peso construction cost calculator (₱25k–₱42k/sqm) with 30-year Pag-IBIG monthly amortization estimates.
- **Founder & Local Leadership Profile**: Spotlights Engr. Giel Rex Besas with verified PRC and PICE credentials.
- **Overcoming Construction Anxiety**: Direct comparison between conventional contractor risks and Giex's fixed-price guarantees.
- **One-Tap WhatsApp & Call Dispatch**: Direct communication channel with Engr. Besas (`0946 050 3038`).
- **Impeccable Design Standard**: Zero anti-patterns, strictly aligned layout grids, and accessible color contrast.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or 20+
- npm or yarn

### Installation

```bash
git clone https://github.com/Japx09/giex-builders.git
cd giex-builders
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.

### Building for Production

```bash
npm run build
npm run start
```
